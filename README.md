# x-deleter

Apaga os próprios tweets no X.

`node scripts/build.mjs` gera `x-deleter.js`. Cole esse arquivo no console de x.com, já logado. O painel abre na lateral direita. O botão Apagar usa as configurações rápidas da tela. Sem transaction id no slot usado, nada é enviado e o log diz qual slot falta. O plano está na issue 1.
